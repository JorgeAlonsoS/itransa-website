# ITRANSA - Ingeniería y Transporte Ayacucho S.A.S.

Sitio web corporativo oficial de ITRANSA, desarrollado a medida sin frameworks externos.

## Tecnologías Utilizadas
- **HTML5**: Semántico y enfocado en la accesibilidad (WCAG).
- **CSS3**: Uso de CSS Variables, Flexbox, CSS Grid y diseño responsivo.
- **JavaScript Vanilla**: Manejo de interacciones, DOM, Intersection Observer y validación de formularios.
- **Iconos**: [Lucide Icons](https://lucide.dev/) vía CDN para rendimiento.
- **Tipografía**: [Inter](https://fonts.google.com/specimen/Inter) vía Google Fonts.

## Estructura de Archivos
```
/
├── index.html          # Estructura principal
├── css/
│   └── style.css       # Hoja de estilos principal
├── js/
│   └── script.js       # Lógica de interacciones
├── assets/
│   ├── images/         # Imágenes optimizadas (Hero, About, Vehículos)
│   ├── documents/      # Archivos PDF (Portafolio)
│   └── icons/          # Iconos locales (si aplica)
├── robots.txt          # Directivas para motores de búsqueda
└── sitemap.xml         # Mapa del sitio para indexación
```

## Características de Desarrollo
- **Performance**: Optimizado sin carga de dependencias innecesarias, imágenes preparadas para lazy-loading y estilos/scripts minimizados conceptualmente.
- **Accesibilidad**: Etiquetas ARIA implementadas, navegación por teclado y alto contraste para textos importantes.
- **SEO**: Meta tags definidos, canonical tag, Open Graph protocols y marcado adecuado.

## Instalación y Uso
1. Clona el repositorio o descarga los archivos.
2. Abre `index.html` en un navegador.
3. No requiere servidor local (Node/Nginx) para desarrollo básico, pero se recomienda un Live Server (VSCode) para probar peticiones relativas si aplican.
